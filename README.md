# 📋 Kanban Task Management Board


<img width="1917" height="926" alt="Screenshot 2026-11-15 155510" src="https://github.com/user-attachments/assets/309a6678-b7a3-46d0-802d-23bdec9b4b67" />


A simple and interactive Kanban Board built using **HTML, CSS, and JavaScript** to organize and manage tasks efficiently.

The application allows users to create tasks, organize them based on their progress, and move tasks between different stages using drag-and-drop functionality.

## ✨ Features

- **Add New Tasks:** Create tasks with a title and description.
- **Three Task Categories:** Organize tasks into:
  - To Do
  - In Progress
  - Done
- **Drag and Drop:** Move tasks between columns to update their status.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Task Counter:** Automatically displays the number of tasks in each column.
- **Local Storage:** Tasks are saved in the browser's local storage, so they remain available even after refreshing the page.
- **Interactive UI:** Clean and user-friendly interface with an interactive task creation modal.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript (Vanilla JS)** – DOM manipulation, event handling, drag-and-drop functionality, and local storage management.

## 💡 How It Works

1. Click the **Add New Task** button to open the task creation modal.
2. Enter a task title and description.
3. Click **Add Task** to create the task in the To Do column.
4. Drag and drop tasks between To Do, In Progress, and Done as their status changes.
5. Use the Delete button to remove tasks.
6. Task counts update automatically, and changes are saved using browser Local Storage.
